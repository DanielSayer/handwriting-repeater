# Guide fonts

Regular-weight Latin WOFF2 fonts, served from our own build assets. Vite gives each file a content-hashed URL. Only the selected font is registered and downloaded; the rest are not preloaded. All six fonts use SIL Open Font License 1.1. Their copyright notices and licences are included here.

QBeginners uses Edu QLD Beginner, the open-source Queensland beginners print face.
